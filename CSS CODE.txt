* { 
padding: 0; 
margin: 0; 
box-sizing: border-box; 
} 
1. * { padding: 0; margin: 0; box-sizing: border-box; }: Applies a zero padding and margin to all 
elements and sets box-sizing to border-box for all elements. This ensures that padding and border are 
included in the element's total width and height. 
*:not(i) { 
font-family: "Poppins", sans-serif; 
} 
2. *:not(i) { font-family: "Poppins", sans-serif; }: Applies the "Poppins" font to all elements except 
for <i> elements. 
body { 
background-color: #ae9cff; 
} 
3. body { background-color: #ae9cff; }: Sets the background color of the body to a light purple 
(#ae9cff).

4. .container { ... }: Sets styles for the container class: 
 background-color: #ffffff;: White background color. 
 width: 90vmin;: Width is 90% of the viewport's minimum dimension. 
 position: absolute;: Absolutely positions the element. 
 transform: translate(-50%, -50%);: Centers the element both horizontally and vertically. 
 top: 50%; left: 50%;: Positions the top-left corner at 50% from the top and left of the viewport. 
 padding: 80px 50px;: Adds padding inside the container. 
 border-radius: 10px;: Rounds the corners with a 10px radius. 
 box-shadow: 0 20px 40px rgba(38, 33, 61, 0.2);: Adds a shadow with a certain blur and spread.
