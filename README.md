# Dictionary App
The Dictionary App is a simple and efficient application that allows users to search for word definitions, synonyms, and antonyms. This app is designed to provide quick and accurate word meanings, making it a useful tool for students, writers, and language enthusiasts.

✨ Features

🔍 Search Word Definitions – Get precise meanings of words instantly.

📝 Find Synonyms & Antonyms – Enhance vocabulary with related words.
